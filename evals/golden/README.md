# Golden set

Единица примера — **полка** (кадр × номер полки). Для каждой полки записана последовательность единиц переднего ряда
слева направо: бренд, вкус, тара, а также чужие единицы. Отсюда получаются:

- эталон счёта — число наших единиц;
- позиционный эталон вкуса;
- эталон тары;
- число чужих («чужие = 0» в отчёте).

Файлы строит `evals/tools/build_golden.py` из исходной разметки проекта (`make golden ARTYOM=…`). Фото в git нет:
поле `file` указывает путь внутри `data/`.

**Итого 26 полок с кадрами** (50 входов с учётом Telegram-вариантов) и ещё 5 полок COMP-1, для которых нужен
кадр. Порог «30 примеров» закрывается, когда найдётся кадр COMP-1: его нужно достать из Telegram или попросить у заказчика.
Второй путь — 1–2 новых полевых кадра, размеченных через экран проверки в кабинете
(`evals/tools/report_to_gt.py --report <id> --frame-id … --file …` превращает утверждённый или исправленный отчёт в GT-файл).

- **Теги edge cases**, метрики считаются и по срезам: `pink_zone` — 20 полок, `foreign_nearby` — 7,
  `unsure_labels` — 5, `pack_geo` — 3, `mixed_packs` — 1.
- **Telegram-вариант** `tg1280` — кадр, ужатый до 1280 px по длинной стороне, JPEG q80, так же как присылает бот.
  Генерируется раннером в `evals/frames_tg/` (не в git).
- **`field_refs_31_08_2026/`** рабочей папки — это крупные планы одного товара на столе. Это не полки, и GT из них
  не строится; они стали полевыми эталонами.
