# BUILD: v7.1 — контраст-правила трёх пар-близнецов (серия E) + вывод литража в таблицу
Проект BURATINO · 2026-07-29 · продолжение `wf2_v7_format_BUILD.md`

## §0. Рамка

Три пары из полевых замеров 29.07: **мандарин-лаванда → манго-маракуйя** (новая, перекос направленный — мандарин зовётся манго), **ревень ↔ клубника-киви** (осталась, слабее), **гуава ↔ помело** (лучше, но добивает не всегда). Механизм у всех один и тот же, что мы разобрали 27.07 на гуаве/помело: цвет-первый шаг кладёт пару в один шорт-лист, мелкие различия на 60–100 px не читаются, модель падает в приор.

Лечение — то самое «точечное контраст-правило пары в SUBTYPE-блок», но теперь для всех трёх пар разом. **Признаки я вывел, разглядывая мокапы эталонов бок-о-бок** (`Vision_Assistance_upload_ALL`), не из памяти. Главная находка: в каждой паре различается **цвет самих крупных букв «Ai TEA»** — самый большой печатный элемент упаковки, читается даже там, где фрукты и мелкий текст уже слились:

| Пара | Буквы «Ai TEA» | Корпус | Крышка ПЭТ |
|---|---|---|---|
| гуава / помело | РОЗОВЫЕ / БЕЛЫЕ | тёмно-зелёный / светло-салатовый | розовая / оливковая |
| мандарин / манго | БЕЛЫЕ / ТЁМНО-БОРДОВЫЕ | светлый жёлто-оранжевый / насыщенный красно-оранжевый | сиреневая / оранжево-коричневая |
| ревень / клубника-киви | БЕЛЫЕ / САЛАТОВЫЕ | светло-розовый / малиновый | ⚠️ обе зелёные — НЕ различает |

Занятная симметрия: во всех трёх парах «жертва» перекоса — вкус с БЕЛЫМИ буквами, а модель тянет в его «цветного» напарника. Похоже на устойчивый приор, правило бьёт прямо в него. Плюс анти-приор строка: «признаки не видны/противоречат → null, НЕ выбирай более привычный вкус».

**Отступление от протокола, сознательное:** строго — одна пара за серию, три правила = три переменные. Пары независимы (не пересекаются по вкусам), поэтому вставляю все три разом; если что-то просядет — бисекция: откатывать по одному правилу. Дешевле, чем три полных серии, а заказчик ждёт.

**Изменение против v7 ровно одно** — блок «ПАРЫ-БЛИЗНЕЦЫ» в конце SUBTYPE (+150–200 токенов промпта) и маркер версии. Схема, FORMAT, детекция, «Парсинг» — нетронуты.

```javascript
  + ' ' + p(t.getUTCHours()) + ':' + p(t.getUTCMinutes()) + ':' + p(t.getUTCSeconds());

const report_id  = 'R_' + Date.now() + '_' + inp.message_id;  // 1 фото = 1 отчёт
const agent_id   = inp.agent_id;
const store_name = inp.store_name;

const rows = (response.items || [])
  .filter(it => it && it.product_name)
  .map(it => ({

    product_name:       it.product_name,

    package_format:     it.package_format || '',    // v7: тара/объём («банка 0,45 л»…), null → пусто

    position:           it.shelf_location,
    front_facing_count: it.front_facing_count,
    item_confidence:    it.confidence,
    overall_confidence: response.overall_confidence
  }));

return rows.length
  ? rows.map(json => ({ json }))
  : [{ json: { report_id, formattedToday, store_name, agent_id,
      product_name: 'ничего не распознано', product_subtype: '', package_format: '',
      notes: response.notes || 'ничего не распознано' } }];
```
