# Промпты: где лежат, как версионируются, как менялись

## Где и как

- **Текущие промпты** лежат в `backend/app/prompts/*.md`: YAML-шапка (`id`, `version`, `pass`, `source`, `status`) и
  тело. Тело уходит в модель байт в байт. `tests/test_prompts.py` проверяет, что `detect_v7.4` и `verify_v9_groups`
  совпадают с текстом из узлов n8n, а `detect_v7.5` — это ровно v7.4 плюс замены 1–3 из `PROMPT_bgcolor_BUILD`.
- **Версия.** Строка `version` попадает в теги LangSmith (`prompt:*`, `verify:*`), в каждый отчёт
  (`prompt_version`) и в ключ кэша evals. Поэтому любую цифру в EVALS.md можно связать с точным текстом, который её дал.
- **Какой промпт активен**, задают `PROMPT_DETECT` и `PROMPT_VERIFY` в `.env` или в конфиге эксперимента.
- **Порядок работы с новой версией:**
  1. новый файл `detect_v7.6.md`, старый не трогать;
  2. `evals/configs/<exp>.yaml` с `prompt_detect: detect_v7.6`;
  3. `make eval CONFIG=…`, не меньше 3 повторов на кадр: σ ошибок подвида между прогонами 0,6–2,8;
  4. строка в таблице ниже и в EVALS.md.
- **История до переноса** лежит в [legacy/prompts/](../legacy/prompts): BUILD-заметки из рабочей папки, где каждая
  версия записана вместе с поломкой, которую чинила. Импорт с редактурой: `legacy/prompts/import_history.py`.

## Как устроен текущий промпт прохода 1

1. **Детекция, а не подсчёт (с v6).** Модель ставит рамку `box_2d` на каждую единицу переднего ряда. Число
   считает программа после IoU-дедупа. Счёт в тексте промпта отлаживать было невозможно, рамки видно глазами.
2. **Справочник перед фото.** 46 эталонов, перед каждым текстовая метка с каноническим именем и брендом.
   Эталоны идут через Files API, поэтому префикс запроса стабилен и кэшируется (до 44K из 50K токенов на 27.08).
3. **`response_schema` с enum.** Бренды — наши плюс `ЧУЖОЙ`; вкусы — 21 каноническое имя (ревень исключён); тара — 8
   форматов. Модель не может придумать SKU.
4. **Вкус — сначала по цвету фона этикетки (v7.5).** Потом по картинке фрукта, в последнюю очередь по цвету
   букв. Для каждого вкуса AI TEA явно задан цвет фона.
5. **Литры не спрашиваются у модели.** Тара ПЭТ считается по ширине рамки относительно банки 0,45 л
   (`format_geo`, пороги 1,25 / 1,43).

## Замеры в новом фреймворке (replay записанных ответов)

Проход 1 без прохода 2 (`n8n_*_replay_pass1`), позиционный скорер:

| промпт | серия | IMG_0644 | IMG_0643 |
|---|---|---|---|
| v7.4 | 31.08–01.09, 9 прогонов | 90,6 % | — |
| v7.5 bgcolor | 01.09 12:18, 4 + 3 прогона | 96,2 % | 98,5 % |
| v7.5 bgcolor | 01.09 13:46, 3 + 3 прогона | 92,3 % | 99,0 % |

- **v7.5 против v7.4.** Замена «цвет букв» → «цвет фона» дала **+2…+6 п.п.** на IMG_0644. Выборка мала,
  σ ошибок между прогонами 0,6–2,8 банки, поэтому вывод «не хуже, скорее лучше».
- **Была ли новая формулировка живой.** В логах прохода 2 серии 12:18 маркер версии ещё `v9-groups`, а у прохода 1
  маркера версии в логах нет вовсе. Поэтому нельзя на 100 % утверждать, что в этой серии работал текст v7.5.
- **Как закрыть вопрос.** Живым A/B-4 на новом ключе: `ab4_prompt_v74` (v7.4 + v9-groups) против `hp_temperature_0`
  (v7.5 + v9), те же 3 кадра × 5 повторов с одинаковыми солями.

## Что вынесли из истории

- **Считает программа, модель только ставит рамки.** Любая попытка «посчитай сама» (v1–v5) была
  неотлаживаемой.
- **Перечисление похожих пар вредит.** Слова «не путай X с Y» провоцируют ту самую ошибку (v7.1–v7.3 → v7.4).
- **Признак должен быть уникальным для класса.** Тип чая и цвет букв повторяются у разных вкусов, цвет фона
  этикетки — почти нет (v7.2 → v7.5).
- **Что можно посчитать геометрией, у модели не спрашиваем.** Литры ПЭТ по ширине рамки стабильнее ответа модели.
- **Одного прогона мало.** σ ошибок подвида 0,6–2,8 при temp 0. Каждое изменение проверяем минимум на 3 прогонах,
  поэтому в раннере есть повторы с солью кэша.
- **Второй проход не бесплатен.** Он добавляет ~45 с и ~35 % стоимости, а по записанным данным точность вкуса
  снижает. Он оставлен только для неуверенных групп и под A/B (ADR-007).
- **Ручная обрезка кадра до зоны товара помогала.** IMG_0644, полка 3: 11/11 против 8/11. Единственный прогон
  66/66 на IMG_0643 — тоже по обрезке. Автокроп по рамкам прохода 1 — следующий кандидат в эксперименты.
